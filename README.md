DeviceViewBundle
================

Symfony bundle that serves the mobile, tablet or desktop view of a site. It works with any
device detection library, lets visitors switch views, remembers their choice and can
redirect each view to its own host.

This bundle continues [MobileDetectBundle](https://github.com/tattali/MobileDetectBundle),
itself based on the original bundle by Nikolay Ivlev.

Work in progress: the first releases are not out yet.
